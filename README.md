# PIR: Human Motion Detection with Passive Infrared Sensors using TinyML

MSc project, Embedded Systems and IC Design, Liverpool John Moores University (completed January 2025).

## Overview
Human motion and direction detection using passive infrared (PIR) sensors and embedded machine learning (TinyML), running on a microcontroller.

- **Sensing:** passive infrared (PIR) sensors
- **Platform:** Arduino Nano 33 BLE Sense
- **Model:** recurrent neural network (RNN) classifier
- **Deployment:** quantized embedded inference
